03 / LABEL SCORES

Summarize correlations

Each label's score is a quantile of its reference-sample correlations. SingleR's default is 0.8; changing it here changes only this toy calculation.

Score tracks: −1 at left, 0 at the tick, +1 at right. Highest score is an initial candidate, not a probability or confirmed identity.

A / SPEARMAN CORRELATION

See how the ranks align

Each point is one selected gene. Matching ranks lie on the diagonal; ties use average ranks. This is the Pearson correlation of the two rank vectors.

ρ = Σ (rᵢ − r̄)(sᵢ − s̄) / √[Σ(rᵢ − r̄)² Σ(sᵢ − s̄)²]

B / WITHIN-LABEL QUANTILE

Follow the interpolation

Choose a synthetic label. Its three reference correlations are sorted; the selected quantile is interpolated between adjacent values.

h = (n − 1) × q; score = x⌊h⌋ + (h − ⌊h⌋)(x⌈h⌉ − x⌊h⌋)

Indices in this formula start at 0. This interpolated quantile is a teaching calculation; it is not a probability.

How is this different from the real analysis?

The synthetic reference profiles and gene names below are illustrative. The real example uses many reference cells, a larger union of pairwise reference markers, SingleR 2.12.0, and fine-tuning and pruning. Its score matrix is pre-fine-tuning; its final label and delta.next are separate outputs. The standard export does not contain a full iteration trace, so this playground does not invent one.
